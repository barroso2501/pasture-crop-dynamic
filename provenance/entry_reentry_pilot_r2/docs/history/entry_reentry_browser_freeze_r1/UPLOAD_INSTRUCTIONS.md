# Instalar o pacote incremental do piloto

Extraia `entry_reentry_pilot_implementation_v1.zip` na raiz do repositório, mantendo as pastas. O pacote contém novos scripts, configurações, testes, método, adendo do plano e instruções. O README é completo, baseado na versão já atualizada após a aceitação dos pares incertos; a versão anterior está preservada em `docs/history/entry_reentry_pre_pilot_20261021_v1/README.md`.

O restante do repositório não é repetido neste ZIP. Mantenha os arquivos anteriores, incluindo os registros de pares incertos. Este pacote não modifica os dados ou a aceitação dos pilotos anteriores, a contabilidade, a matriz v4.3 ou events-v5. Os quatro arquivos nativos históricos em `config/reference_native/` são cópias exatas para validação local; não são novas execuções. Preserve-os junto do pacote de reprodução. Os dois scripts históricos de referência não são os scripts que você deve executar agora.

`COMECE_AQUI_PT.md` e este arquivo de instruções passam a apontar para o novo piloto. Suas versões imediatamente anteriores foram preservadas junto ao README anterior. Os documentos antigos do plano 009 permanecem com seus textos datados; o novo adendo de execução registra o estado atual.

`PACKAGE_SHA256.csv` cobre todos os arquivos deste pacote, exceto ele próprio. `config/entry_reentry_source_snapshots_v1.json` fixa os bytes de código, configuração, testes e referências. Não há resultados nativos novos, publicação GitHub, depósito DOI ou execução GEE neste pacote.
