# Phase 9A.2 — terminology result

Phase 9A.2 resolves the ambiguity in the English name of `TMP`. The class label
is **Temporary Crop**, and ordinary prose uses **temporary crops**. The
Portuguese definition remains *agricultura temporária*: annual or seasonal
crops, not agriculture that is necessarily temporary at a location.

The correction affected five phrase occurrences in four evidence records:
P9A031, P9A033, P9A034, and P9A035. It also produced revised versions of the
two Phase 9A.1 figures. No result was recalculated, and the interpretation of
RQ1 or RQ2 did not change.

Technical notation is intentionally stable. `TMP`, `NAT→TMP`, `PAS→TMP`, and
field names containing `tmp` remain valid. **Other Agriculture** (`OAG`) is a
different class and was not renamed or combined with TMP.

The terminology-harmonized evidence matrix v3 is the current source for new
English-language writing. The older matrices remain available to preserve the
exact historical state of the analysis at each accepted phase.
