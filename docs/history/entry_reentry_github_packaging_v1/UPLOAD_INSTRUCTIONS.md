# Instalar o registro de aceitação completa

Extraia `entry_reentry_full_acceptance_record_v1.zip` na raiz do projeto, preservando as pastas. O pacote inclui a implementação distribuída, todos os 73 CSVs nativos recebidos, os sete produtos originais do validador, a revisão complementar, os resultados e o README completo atualizado.

Nenhum script, configuração, referência crítica ou arquivo do piloto preservado foi alterado. O texto anterior do README e das instruções foi arquivado em `docs/history/entry_reentry_before_full_acceptance_v1/`. Relatórios anteriores mantêm seus status históricos. O novo registro de aceitação completa é a autoridade desta etapa. O relatório JSON PASS e os seis CSVs derivados mantêm os bytes originais gerados pelo validador.

`PACKAGE_SHA256.csv` cobre todos os arquivos deste ZIP, exceto ele próprio. O pacote conserva a contabilidade, a matriz v4.3/events-v5 e os arquivos do piloto. Não executa publicação GitHub ou DOI. Não é necessário repetir tarefas GEE. A etapa seguinte é a incorporação científica dos resultados completos.
