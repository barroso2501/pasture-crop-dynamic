# Decision 021 — English terminology for TMP

## Decision

The stable analytical code `TMP` continues to represent Portuguese
*agricultura temporária*. English-language class labels will use **Temporary
Crop**. Running prose will use **temporary crops**, and compound modifiers may
use **temporary-crop**.

The expression **temporary agriculture** is deprecated in project-authored
English because it can imply that the agricultural land use itself is
temporary. The intended meaning is that the crops are annual or seasonal.

## Scope

The change applies only to human-readable English labels, prose, legends,
figure titles, and manuscript text. It does not rename:

- `TMP`, `tmp`, or any class value;
- `NAT→TMP` or `PAS→TMP`;
- fields beginning with `nat_tmp_`, `pas_tmp_`, or `tmp_`;
- metrics, findings, source identifiers, or file names;
- the separate `OAG` / **Other Agriculture** class.

## Provenance

Accepted Phase 9A v1 and Phase 9A.1 v2 files remain immutable. Phase 9A.2
creates derivative v3 evidence products and revised figures. No area,
proportion, trajectory, spatial statistic, or inferential result is
recalculated.

Where an exact historical quotation or external source uses another label, the
source wording may be retained with an explanatory crosswalk.
